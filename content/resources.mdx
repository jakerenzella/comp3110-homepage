# Resources

These are some tools and readings we have found helpful.

## Tooling

- [Git & GitHub](https://docs.github.com/): you should be familiar from Gitlab in COMP1531.
- [DVC](https://dvc.org/): version control for data and models.
- [Weights & Biases](https://wandb.ai/): experiment tracking and dashboards.
- [Docker](https://docs.docker.com/): packaging your tools so they run everywhere.
- [FastAPI](https://fastapi.tiangolo.com/): a straightforward way to serve a model
  behind an API.

## Readings

- *Designing Machine Learning Systems* — Chip Huyen (O'Reilly, 2022). The closest
  thing to a textbook for this course.
- [Rules of Machine Learning](https://developers.google.com/machine-learning/guides/rules-of-ml)
  — Google's field guide to ML engineering.
- [The ML Test Score](https://research.google/pubs/pub46555/) — a rubric for
  production-readiness.
- [Hidden Technical Debt in Machine Learning Systems](https://papers.nips.cc/paper/2015/hash/86df7dcfd896fcaf2674f757a2463eba-Abstract.html)
  — why ML systems rot.
